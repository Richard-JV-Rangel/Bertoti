## Meus Projetos (APIs - Aprendizagem por Projetos Integrados)

### Em 2026-1 (3º Semestre)

### Empresa Parceira: [IPEM - Instituto de Pesos e Medidas (Regional São José dos Campos)]

### Problema:
O controle de abastecimento e a gestão das viaturas da frota do IPEM eram realizados de forma estritamente manual, utilizando pranchetas físicas mantidas nos veículos. Esse processo gerava lentidão na consolidação dos dados mensais, impossibilitava a análise comparativa de consumo entre diferentes veículos e comprometia a rastreabilidade das informações e rotas, dificultando a geração de indicadores gerenciais confiáveis.

### Solução Entregue pela Equipe:
Foi desenvolvido o **FlowTrack**, uma Plataforma de Controle de Abastecimento e Utilização de Viaturas web. O sistema substituiu o controle manual de pranchetas por um ambiente digital, permitindo o registro seguro de abastecimentos, início e término de uso dos veículos, mantendo o histórico completo de quilometragem e despesas. A aplicação forneceu uma base de dados sólida e relatórios consolidados para a gestão eficiente da frota do IPEM.

#### Tecnologias Utilizadas
> - **Java & Spring Boot**: Base da infraestrutura back-end, responsável pela regra de negócios e criação das APIs REST.
> - **MySQL**: Banco de dados relacional escolhido para armazenar os registros das viaturas, técnicos e abastecimentos.
> - **HTML, CSS e JavaScript**: Ferramentas aplicadas na construção da interface web e no consumo dinâmico das APIs desenvolvidas no back-end.
> - **Git, GitHub e Jira**: Ecossistema utilizado para controle de versão, colaboração no código e gestão ágil das tarefas da equipe.
